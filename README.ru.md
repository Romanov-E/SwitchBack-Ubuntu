# SwitchBack Ubuntu 🔄

[![GNOME Shell](https://img.shields.io/badge/GNOME%20Shell-45%20%7C%2046%20%7C%2047%20%7C%2048%20%7C%2049%20%7C%2050%20%7C%2051-blue.svg)](https://extensions.gnome.org/)
[![Session](https://img.shields.io/badge/Сессия-Wayland%20%7C%20X11-success.svg)](#архитектура)
[![Ubuntu](https://img.shields.io/badge/Ubuntu-24.04%20%7C%2024.10%20%7C%2025%20%7C%2026-orange.svg)](https://ubuntu.com)
[![GitHub](https://img.shields.io/badge/Автор-Romanov--E-blue?logo=github)](https://github.com/Romanov-E)
[![Лицензия: MIT](https://img.shields.io/badge/Лицензия-MIT-green.svg)](LICENSE)

**SwitchBack Ubuntu** — нативная утилита и расширение для GNOME Shell, реализующее умное автопереключение раскладки клавиатуры в Linux (создано по мотивам Windows-утилиты [*Switchify*](https://github.com/JD72/Switchify) автора [JD72](https://github.com/JD72)).

Позволяет переключать язык ввода по клавише `Caps Lock`, отображает настраиваемые анимированные полосы-индикаторы (в одиночном или парном режимах) и автоматически возвращает раскладку на приоритетную (например, английскую) после паузы в наборе текста.

---

## ✨ Возможности

- ⌨️ **Переключение по Caps Lock (с возможностью отключения):**
  - Быстрое переключение раскладки одиночным нажатием клавиши `Caps Lock`.
  - Включается и отключается прямо в окне настроек: при выключении работают стандартные системные комбинации (Super+Пробел, Alt+Shift).
- ⏱️ **Умный автовозврат при паузе:** Если вы закончили печатать по-русски, через заданное время (например, 2–5 секунд) раскладка сама возвращается на английский. Пока вы печатаете — таймер непрерывно сбрасывается.
- 📏 **Полная кастомизация индикатора (одиночный и парный режимы):**
  - **Положения на экране:**
    - Сверху (горизонтально)
    - Снизу (горизонтально)
    - **Сверху + Снизу (две горизонтальные полосы одновременно)**
    - Слева (вертикально)
    - Справа (вертикально)
    - **Слева + Справа (две вертикальные полосы одновременно)**
  - **Индивидуальные отступы от краёв:** Независимая настройка зазоров для каждой стороны экрана: сверху, снизу, слева и справа (в пикселях).
  - **Геометрия:** Толщина (1–40 px), Длина (от 5% до 100% стороны экрана), Скругление углов (от 0 до 25 px).
  - **Цвет и прозрачность:** Системная палитра, HEX-коды или полупрозрачные оттенки.
  - **Стили анимации:** Сжатие к центру (с двух сторон), к началу (влево/вверх) или к концу (вправо/вниз).
- 🎛️ **Иерархия настроек и гибкие режимы:**
  - **Тихий режим (Silent):** Автовозврат активен, а визуальная индикация отключена (работает незаметно в фоне).
  - **Полная деактивация:** При отключении функции автовозврата экранный индикатор автоматически выключается.
- 🖱️ **Аппаратная изоляция клавиатуры (никаких ложных срабатываний):**
  - Слушает физические события клавиатуры ядра Linux (`/dev/input/event*`).
  - **Движения мыши, клики ЛКМ/ПКМ и вращение колёсика (включая боковое колесо под большой палец на мышах вроде Logitech MX Master) НИКОГДА не сбивают таймер!**
- 🛡️ **Безопасность и конфиденциальность:**
  - **Никакого кейлоггинга:** SwitchBack НЕ сохраняет, НЕ логирует и НЕ передаёт нажатые символы или текст. Демон фиксирует только сам факт нажатия клавиши для сброса счётчика времени.
  - **Без root-прав:** Фоновый демон работает как пользовательская служба (`systemd --user`).
  - **Защищённый IPC:** Файл в оперативной памяти RAM (`/dev/shm/switchback_key`) защищён правами `0600` (доступ только текущему пользователю).
- ⚙️ **Встроенное управление службой прямо из настроек:**
  - Запуск, остановка, автозагрузка и перезапуск демона в один клик через интерфейс расширения.

## 📸 Архитектура решения

```
                  ┌──────────────────────────────────────────────┐
                  │        Физическая клавиатура (/dev/input)    │
                  └──────────────────────┬───────────────────────┘
                                         │ Только события EV_KEY
                                         ▼
                  ┌──────────────────────────────────────────────┐
                  │       SwitchBack Демон (systemd --user)      │
                  │   Фильтрует все кнопки, скролл и жесты мыши  │
                  └──────────────────────┬───────────────────────┘
                                         │ Таймштамп в RAM (0600)
                                         ▼
                  ┌──────────────────────────────────────────────┐
                  │          Общая память RAM (/dev/shm)         │
                  └──────────────────────┬───────────────────────┘
                                         │ Мгновенное чтение (0% CPU)
                                         ▼
                  ┌──────────────────────────────────────────────┐
                  │        GNOME Shell Extension (Wayland)       │
                  │    • Плавная 60 FPS анимация полос           │
                  │    • Автовозврат через InputSourceManager    │
                  │    • Мгновенный Hot-Reload из окна настроек  │
                  └──────────────────────────────────────────────┘
```

## 🚀 Установка

Склонируйте репозиторий и запустите автоматический установщик:

```bash
git clone https://github.com/Romanov-E/SwitchBack-Ubuntu.git
cd SwitchBack-Ubuntu
./install.sh
```

### Что делает скрипт `install.sh`:
1. Проверяет системные пакеты (`python3`, `glib-compile-schemas`, `gnome-extensions`).
2. Добавляет пользователя в системную группу `input` (для безопасного чтения устройств ввода без прав root).
3. Компилирует схему GSettings и устанавливает расширение GNOME Shell.
4. Разворачивает и запускает службу `systemd --user` фонового демона клавиатуры.
5. Активирует расширение.

> ⚠️ **Важно:** Если при установке вас впервые добавили в группу `input`, выполните **Выход из сеанса (Log Out)** и войдите снова, чтобы права ядра вступили в силу.

## ⚙️ Настройка параметров

Настройки открываются через системное окно управления расширениями:
- **Приложение «Расширения» / «Менеджер расширений» GNOME:** нажмите кнопку шестерёнки ⚙️ рядом со **SwitchBack Ubuntu**.
- **Командой в терминале:**
  ```bash
  gnome-extensions prefs switchback@local
  ```

Все изменения применяются **мгновенно на лету** прямо во время перемещения переключателей и ползунков.

---

## 🧹 Чистое удаление

Если вы захотите полностью удалить SwitchBack:

```bash
cd SwitchBack-Ubuntu
./uninstall.sh
```

Скрипт остановит службу, удалит демон, расширение и схему настроек из системы, вернув всё в исходное состояние.
